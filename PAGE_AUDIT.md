## Design Patterns
1. **Service Card Pattern**: Number + Title + Description + Timeline + Price + Learn More link
2. **Process Steps**: Numbered/titled steps with descriptions
3. **Feature Highlights**: Icon + Title + Description (3-4 column grid)
4. **FAQ Pattern**: Collapsible accordion sections
5. **CTA Pattern**: Consistent placement of phone + consultation buttons
6. **Sidebar Pattern**: Contact info or related links on right side of pages
